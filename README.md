# Praveen Babu — Portfolio

A responsive React + Vite portfolio focused on GenAI, backend engineering, and agentic systems.

## Run locally

1. Install Node.js (LTS).
2. Extract this folder and open it in VS Code.
3. Run:

```bash
npm install
npm run dev
```

4. Open the local URL printed by Vite (usually http://localhost:5173).

## Build for deployment

```bash
npm run build
npm run preview
```

The production site is generated in `dist/`. You can deploy it to Vercel, Netlify, or any static hosting provider.
